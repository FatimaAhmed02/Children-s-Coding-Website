🎨 Let's Build a Mini Profile Page! 🎨

In this lesson, you'll learn how to create a simple and **beautiful profile page** with HTML and CSS.

📺 Watch & Learn: Profile Page Tutorial

📌 Step 1: Setting Up the HTML

Every webpage starts with **HTML**. Here's how we structure our profile page:

<div class="profile">
  <h1>My Profile</h1>
  <img src="profile.jpg" alt="Profile Picture">
  <button>Follow Me</button>
</div>

🎨 Step 2: Adding CSS for Styling

Now, let's make it **beautiful** with CSS!

.profile {
  background-color: lightblue;
  text-align: center;
  border-radius: 10px;
  padding: 20px;
}
