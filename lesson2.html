🎨 Let's Learn CSS! 🎨

CSS makes websites beautiful and stylish! Let's explore how to use it.

1. What is CSS? 🤔

CSS (Cascading Style Sheets) is used to design and style webpages!

2. How Does CSS Work? ⚙️

CSS tells the browser how elements should look (color, size, position, etc.).

3. Types of CSS 🏗️

There are three main ways to use CSS:

<!-- 1. Inline CSS (inside an HTML tag) -->
<p style="color: red;">I am red!</p>

<!-- 2. Internal CSS (inside <style> in HTML) -->
<style>
  p { color: blue; }
</style>

<!-- 3. External CSS (separate file) -->
<link rel="stylesheet" href="style.css">

4. Basic CSS Syntax 🖥️

selector {
  property: value;
}

5. Changing Colors 🎨

You can change the color of text using color.

p { color: red; }

6. Changing Fonts ✍️

CSS can change the font style.

p { font-family: "Arial", sans-serif; }

7. Backgrounds & Borders 🌅

We can add background colors or border styles.

body { background-color: lightblue; }
p { border: 2px solid black; }

8. Spacing (Margin & Padding) 📏

Margin = space outside an element. Padding = space inside an element.

div { margin: 10px; padding: 20px; }

9. Text Styling ✨

We can change text size, boldness, and alignment.

h1 { font-size: 40px; font-weight: bold; text-align: center; }

10. The CSS Box Model 📦

Everything in CSS is a box (with width, height, padding, and margin).

div { width: 200px; height: 100px; padding: 10px; border: 2px solid black; }
