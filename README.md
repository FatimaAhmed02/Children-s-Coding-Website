# Children’s Coding Website

A web project built to explore how front-end interfaces can connect to backend services, while focusing primarily on user-friendly design for children.

## 🌐 Live Website
🔗 https://fatimaahmed02.github.io/Children-s-Coding-Website/

## 🛠 Tech Stack
### Frontend
- React
- HTML5
- CSS3

### Backend (Learning / Assisted)
- Node.js (guided setup)
- MongoDB (basic usage)

## ✨ Features
- Responsive, child-friendly UI
- Clean and structured layouts
- Frontend integration with backend endpoints (learning-focused)
- Data handling explored with guidance
