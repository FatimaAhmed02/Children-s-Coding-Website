🔥 Let's Learn HTML! 🔥

HTML is the building block of websites! Let’s explore its most important tags:

1. The <html> Tag 🌐

This tag tells the browser that everything inside is an HTML document.

<html>
  <!-- Everything inside here is HTML! -->
</html>

2. The <head> & <title> Tags 🧠

The <head> contains hidden info like the page title.

<head>
  <title>My First Webpage</title>
</head>

3. The <body> Tag 🏗️

This is where all the fun happens! Everything visible goes inside.

<body>
  <h1>Welcome to My Page!</h1>
</body>

4. Headings: <h1> to <h6> 📝

Headings define the title sizes. <h1> is the biggest, <h6> is the smallest.

<h1>Big Title</h1>
<h3>Medium Title</h3>
<h6>Smallest Title</h6>

5. The <p> Tag ✍️

This tag adds paragraphs of text.

<p>This is a paragraph!</p>

6. The <a> (Link) Tag 🔗

Want to link to another page? Use <a>!

<a href="https://www.google.com">Click to visit Google!</a>

7. The <img> (Image) Tag 🖼️

Show images on your page!

<img src="https://www.example.com/image.jpg" alt="A cool image">

8. The <ul> & <ol> (Lists) Tags 📜

Unordered (bullet points) & Ordered (numbered) lists.

<ul>
  <li>Apples</li>
  <li>Bananas</li>
</ul>
<ol>
  <li>First Item</li>
  <li>Second Item</li>
</ol>

9. The <div> Tag 🏠

<div> is an invisible box that helps organize content.

<div>
  <p>This is inside a div!</p>
</div>
