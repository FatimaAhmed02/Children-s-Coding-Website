✨ Let's Learn Buttons & Hover Effects! ✨

Buttons are an important part of a webpage! Let’s learn how to style them.

📺 Watch & Learn: Creating Buttons

1. Creating a Button

We create buttons using the <button> tag.

<button>Click Me!</button>

2. Adding Styles

We use CSS to change the **color**, **size**, and **shape** of buttons.

button { background-color: blue; color: white; padding: 10px 20px; border-radius: 8px; }

3. Adding a Hover Effect

Hover effects make buttons change when the mouse moves over them.

button:hover { background-color: red; transform: scale(1.1); }
